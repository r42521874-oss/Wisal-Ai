# corpus الحالي
ثلاثة مقاطع عربية: النحل 125، طه 44، آل عمران 159. جلبت عبر API موسوعة القرآن الكريم بعد التحقق من السورة والآية. نصوص الآيات محفوظة كما رجعت من المصدر؛ لا نقوم بتوليدها. ترجمة English Saheeh تحدد مسار API فقط؛ الحقل المفهرس arabic_text وليس ترجمة مولدة. ليست آراء فقهية أو تحققًا لجميع الادعاءات. حفظ الأرقام والاقتباسات لا يضمن حفظ المعنى. تمنع policy مصادر غير القائمة المحددة في SOURCES.md.
