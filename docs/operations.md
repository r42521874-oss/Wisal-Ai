# التشغيل والاستمرار

## الاعتمادات
Render Static Site + Web Service Free، Node 24، Express، وكيل ElevenLabs العام. API لا يسجل نص المستخدم؛ السجلات التشغيلية تتضمن رمز الخطأ ومعرف الطلب فقط. مزود ElevenLabs قد يحتفظ بالمحادثة وفق سياساته وإعدادات مالك الوكيل؛ لم يثبت تفعيل عدم الاحتفاظ.

## الجاهزية
فحص /api/health يثبت حياة الخادم والفهرس، ولا يثبت رصيد الوكيل أو نجاح المحادثة. قبل التحكيم يُجرى طلب تحليل قصير ويُفحص تقريره. الخطة المجانية قد تتوقف عند الخمول؛ لا ندعي تشغيلًا دائمًا. الواجهة توضح المهلة وإعادة المحاولة ولا تعرض استجابة ثابتة بديلة كأنها من AI.

render.yaml يصف إعداد healthCheckPath لخدمات Blueprint الجديدة/المربوطة؛ لا يطبق هذه الخاصية على خدمة قائمة بمجرد رفع الملف. إعداد NODE_VERSION ومعرف الوكيل يمكن تحديثه دون تغيير الخطة. لا ترقية مدفوعة تلقائية.

## التكلفة
سعر الاستضافة في الخطة الحالية: 0 دولار ضمن الحدود المجانية. التكلفة المتغيرة: رصيد محادثات ElevenLabs حسب خطة صاحب الحساب والنموذج والتوكنات. لا يوجد وصول لفاتورة الحساب لتأكيد سعر الطلب. طلب التحسين يستخدم محادثتين عادة، وحتى أربع عند محاولة إصلاح معنى واحدة وفحصها، والتحليل فقط محادثة؛ الرفض المحلي لا يستهلك محادثة.

معادلة الميزانية: تكلفة الاستضافة + (عدد التحليلات فقط × متوسط تكلفة محادثة) + (عدد التحسينات × متوسط تكلفة ٢–٤ محادثات). يجب قياس استهلاك 20 طلبًا من لوحة صاحب الحساب قبل اعتماد ميزانية. راجع https://render.com/docs/free وhttps://elevenlabs.io/pricing/agents-platform عند اعتماد خطة مدفوعة.

## مسؤوليات الصيانة المقترحة
مسؤول تقني: مراقبة الأخطاء والتبعيات والنسخ وإعادة الاختبارات قبل النشر. مسؤول محتوى: مراجعة corpus والمصادر وتحديث السجل. مسؤول المنتج: قياس الأثر والموافقات وتحسين UX. أسماء أصحاب الأدوار تعتمد من الفريق، وليست مختلقة هنا.

## استمرار الخدمة
لا تبديل تلقائي لمزود أو مصدر غير معتمد. عند تعطل الوكيل: احتفظ بنصك محليًا، أعد المحاولة أو تابع مراجعة بشرية. لا يوجد ادعاء بديل AI مُنفذ. الخطوة التالية: مراجعة بشرية ودراسة أثر محدودة ثم تعميم corpus داخل المصادر التسعة بحقوق واضحة.
