# قائمة التسليم النهائي

- [x] مستودع عام بالكود والتبعيات وملف القفل وأدلة الاختبارات.
- [x] نموذج منشور يتصل فعليًا بوكيل ElevenLabs.
- [x] المصادر التسعة المطلوبة والعبارة البديلة على الموقع وفي التوثيق.
- [x] فهرس محدود موثق، وإظهار مصادر كل طلب.
- [x] اختبارات الإدخال والمخرجات والطلبات الحساسة، مع حدود صريحة.
- [x] عرض بالقالب الرسمي: عشر شرائح أساسية لخمس دقائق وثلاث ملاحق للأسئلة.
- [x] نص إلقاء بمجموع ٣٠٠ ثانية ورسم مبني على سجلات فعلية.
- [x] فيديو شرح مرئي صامت دون دقيقتين، بمشاهد من واجهة الموقع.
- [ ] إدخال أسماء الفريق وأدواره الحقيقية في بيانات المشاركة (لا تُختلق).
- [ ] مراجعة مختص للمضمون الديني؛ النظام لا يمنح اعتمادًا شرعيًا.
- [ ] قياس أثر بشري بمقارنة عمياء وموافقة المشاركين؛ ليس منجزًا تقنيًا قابلًا للاستبدال بأرقام الاختبارات.
- [ ] تأكيد تسجيل المسار المفتوح في بوابة الهاكثون؛ ملاءمة الفكرة لا تثبت التسجيل.
- [ ] تأكيد /api/health في لوحة الخدمة القائمة؛ render.yaml ملف مرجعي ولا يطبّق تلقائيًا على الخدمة الموجودة.
- [ ] رفع العرض والفيديو وروابط الموقع والمستودع إلى بوابة التسليم من حساب المشاركة.

الاستضافة المجانية قد تمر بتشغيل بارد. افتحي الموقع قبل العرض، وأبقي الفيديو والنسخة PDF جاهزين. لا يوجد وعد بالفوز أو حكم منظم بشأن اكتمال الأهلية.
