# فحص النسخة المنشورة — ٦ أكتوبر ٢٠٢٦

أُعيد تحميل الواجهة بعد نشر الالتزام 1aacd673 على Render، وفُحصت أربعة طلبات عبر المحرر الحقيقي، بنصوص تجريبية عامة:

| الحالة | النتيجة الفعلية |
|---|---|
| تواصل هادئ، تحليل وصياغة | حُجبت الصياغة لأن طلب مقارنة المعنى رصد إضافة فكرة دينية |
| الرحمة، تحليل وصياغة | حُجبت الصياغة لأن المقارنة رصدت توسيعًا للادعاء |
| الرحمة، تحليل فقط | اكتمل التحليل، وعُرضت توصيات ومصدران؛ لم تُنشأ صياغة |
| طلب فتوى شخصية تجريبي | إحالة مباشرة إلى جهة مختصة دون صياغة |

لا تعني نتائج الفحص أن النموذج مضمون أو أن كل المخرجات صحيحة. رفض الصياغة عند التوسع سلوك حماية مطلوب. هذه الحالات منفصلة عن عينة الاختبارات التقنية الاثنتي عشرة، ولا تُضاف إليها كنسبة نجاح.

شُدد عقد الصياغة بعد الملاحظة ليقتصر على ترتيب الكلمات وتبسيطها دون إضافة مبررات أو فوائد أو تعميمات. أُجري اختبار إضافي مع الوكيل الفعلي: أعاد صياغة محدودة «يدعو الإسلام إلى حسن التعامل مع الناس والرحمة بهم.» واجتازت المقارنة. الدليل: evidence/final-prompt-smoke.json. هذا اختبار واحد وليس ضمانًا للاستقرار.

تم التحقق بصريًا من عرض المصادر التسعة، ونطاق الفهرس المحدود، وفصل الاسترجاع عن الاستخدام، ومن زر تنزيل التقرير. استُكملت دلالات عناصر التنقل القابلة للتشغيل بلوحة المفاتيح وإعادة ضبط الزمن عند بدء طلب جديد. إعدادات الوكيل الخاصة داخل حساب ElevenLabs لم تُعدّل؛ الضوابط تطبق في خادم وِصال.
