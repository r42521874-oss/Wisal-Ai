# سجل الأدوات والمصادر والحقوق

| المكون | الاستخدام | الحقوق/الإفصاح |
|---|---|---|
| Node.js | تشغيل الخدمة | تراخيصه الأصلية: https://github.com/nodejs/node/blob/main/LICENSE |
| Express 5.1 | HTTP | MIT؛ تراخيص الاعتمادات في حزم npm؛ إصدارات مثبتة في package-lock.json |
| ElevenLabs | تحليل ومراجعة عبر الوكيل | خدمة تجارية بشروط المزود؛ لا نملك أو ننشر النموذج؛ معرف الوكيل فقط |
| QuranEnc | ثلاثة نصوص عربية قصيرة | المصدر والموضع وتاريخ الجلب في corpus؛ لا تُمنح رخصة لإعادة توزيع مكتبة المصدر بالكامل |
| Tajawal / Google Fonts | واجهة عربية | SIL OFL حسب سجل الخط: https://github.com/google/fonts/tree/main/ofl/tajawal |
| قالب التحدي / Readex Pro | العرض | قالب مشاركين قدمه المنظم لهذا التحدي؛ حفظ الهوية؛ الخط حسب رخصته الأصلية |
| أدوات الذكاء الاصطناعي المساعدة | كتابة كود وتوثيق ومواد عرض | استُخدمت للمساعدة في التطوير؛ ليست مراجع شرعية ولا بديلًا عن فحص المنتج |

حقوق الكود الأصلي والمساهمات يتعين أن يملك الفريق حق نشرها كما يطلب الدليل. لا نفرض رخصة جديدة على عمل لم يحدد مالكه ترخيصه. هذا السجل لا يغني عن مراجعة الحقوق عند توزيع تجاري. لا تنشر بيانات مستفيدين أو أسرار أو ملف حساب الوكيل الكامل.
