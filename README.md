# وِصال | Wisal AI

أداة عربية لتحليل أسلوب الرسالة في التعريف بالإسلام ومراعاة الجمهور الذي يحدده الكاتب، مع اقتراح صياغة وفحوص آلية محدودة. لا تصدر فتاوى ولا تمنح تصديقًا شرعيًا.

- **الموقع:** https://wisal-ai.onrender.com
- **الخادم:** https://wisal-ai-api.onrender.com
- **الصحة:** https://wisal-ai-api.onrender.com/api/health
- **المنهجية:** https://wisal-ai-api.onrender.com/api/methodology
- **المسار المقترح:** المسار المفتوح؛ تحليل الانطباع وأسلوب التواصل قبل تقديم الرسالة، وليس ترجمة أو روبوت فتاوى. اعتماد المسار النهائي لدى المنظم.

## المستخدم والمشكلة
المستخدم المباشر: المعرّف بالإسلام أو صانع المحتوى العربي. المستفيد النهائي: الجمهور الذي يتلقى الرسالة. المشكلة: وضوح وصحة الفكرة لا يضمنان ملاءمة أسلوب تقديمها للجمهور. يتيح وِصال مقارنة الأصل والاقتراح ومعرفة حدود الفحص والمراجع قبل اعتماد الكاتب.

## ما يعمل الآن
1. النص + جمهور عام/عقلاني/روحي + وصف اختياري + هدف محدد.
2. فحص نطاق: رصد محدود لطلبات فتوى واختلاق مصادر وتجاوز التعليمات وبيانات شخصية وتحريض.
3. استرجاع بالكلمات المفتاحية من ثلاث آيات موثقة من QuranEnc عن التواصل؛ قائمة المراجع التسعة ثابتة دون بدائل.
4. إرسال البيانات والمقاطع إلى وكيل ElevenLabs الحقيقي عبر WebSocket في الوضع النصي.
5. فحص شكل الرد والاقتباسات والأرقام ومعرفات المراجع، ثم طلب مراجعة معنى منفصل من الوكيل نفسه عند وجود اقتراح.
6. محاولة إصلاح التغير المكتشف في المعنى ثم حفظ الأصل مع توضيح السبب إن استمر؛ تعذر المقارنة وحده لا يحجب الصياغة. حفظ نص أصلي للمقارنة، تحرير الاقتراح، نسخ وتنزيل تقرير محلي.
7. إقرار إرسال النص إلى المزود، وبيان الخصوصية دون تخزين نصوص المستفيدين في خادم وِصال.

## النطاق والقيود
- اللغة المتاحة للواجهة والسيناريو المقاس: العربية. لا ندّعي توطينًا لكل اللغات.
- لا تُبحث المصادر التسعة كاملة. المفهرس فعليًا ثلاثة مقاطع من مصدر واحد؛ توضح الواجهة الفرق بين المصدر المعتمد، والمقطع المسترجع، والاستشهاد المستخدم.
- الفحوص غير شاملة. استخدام الوكيل نفسه للتحليل والمراجعة قد يكرر الخطأ؛ لا يعادل مراجعة بشرية مستقلة.
- لا توجد دراسة بشرية مكتملة تثبت زيادة الفهم أو الإقناع. الأدلة المنشورة اختبارات تقنية على أمثلة مصطنعة.
- لا تطلب الأداة تصنيف ديانة المستفيد أو استنتاج سمات حساسة؛ الجمهور اختيار الكاتب.
- لا تُستخدم للمحتوى الفقهي الشخصي. النص الديني يحتاج مراجعة مختص قبل النشر.

## التشغيل وإعادة الاختبار
Node.js 24 (LTS) موصى به؛ النطاق المدعوم في package.json. `npm ci` ثم `npm start`، وافتح http://localhost:3000.

```sh
npm ci
npm test
npm run check
npm start
```

`npm run test:live` يجري 12 طلبًا على نصوص اختبار عامة، ويستخدم الوكيل الحقيقي وقد يستهلك رصيدًا. يبدأ خادمًا محليًا مؤقتًا ويكتب أدلة JSON في docs/evidence. لاستهداف النسخة المنشورة: `EVALUATION_URL=https://wisal-ai-api.onrender.com npm run test:live`.

## الإعدادات
- `PORT`: يحدده Render تلقائيًا؛ محليًا 3000.
- `ELEVENLABS_AGENT_ID`: الافتراضي هو الوكيل المتصل بالمشروع.
- `ELEVENLABS_API_KEY`: اختياري للوكيل العام، ولا يرسل للمتصفح. الوكيل الخاص يتطلب مفتاحًا مخولًا ومسار signed URL.
- `ALLOWED_ORIGINS`: نطاقات الواجهات المسموح بها. الحد 8 طلبات/دقيقة/عنوان وثلاثة طلبات وكيل متزامنة، حماية أساسية وليست مقاومة كاملة للإساءة.
- `NODE_VERSION=24`: يثبت خط إصدار التشغيل على Render.
- لا تحفظ مفاتيح أو بيانات مستفيدين في المستودع.
